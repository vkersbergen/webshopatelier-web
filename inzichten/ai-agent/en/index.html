Which task should you give your store’s first AI agent?

By WebshopAtelier · Updated 21 November 2026

A good first task comes up often, draws on a reliable source and produces something you can review quickly. Drafting replies to returns enquiries fits the bill if your returns policy is current. You can check the answer before it reaches the customer.

In this article
  • When will ordinary automation do?
  • Define what a finished task looks like
  • Test when the agent should stop
  • Calculate the time you actually save

When will ordinary automation do?

An order confirmation with fixed fields and one predictable next step suits a standard automation. Incoming customer enquiries need interpretation. Someone has to identify the request, find the relevant policy and decide when to involve a colleague. These are specific skills you can test an agent on. Anthropic explains the distinction between predefined workflows and tasks where software chooses the steps. Read Anthropic’s explanation.

Define what a finished task looks like

Write the brief as you would for a new employee. For a returns enquiry, ask the agent to read the email, check the purchase date against the current returns policy, draft a reply and flag any missing details. Have it refer refunds or exceptions to you for approval. You can then see exactly which decisions are still yours.

Test when the agent should stop

Choose three anonymised messages from your inbox: a routine return, one with a missing order number and a request outside the returns window. Write down the correct next step for each before testing. Check the replies for promises you cannot honour, invented information and overlooked exceptions.

Calculate the time you actually save

Measure how long it takes to reply manually. Subtract the time spent reviewing drafts, making corrections and handling exceptions. A draft produced in seconds can still cost more if it needs substantial rework. Expand the task when both the time saved and the quality of the replies justify it.

Suppose you receive twenty returns enquiries a week. If a manual reply takes six minutes and checking a draft takes two, you free up eighty minutes before exceptions and maintenance. Time both tasks for a week. To run that trial, consider a custom agent for a single task or the customer service assistant within Commerce 360.
